# Definition of Done

A feature is done only when:

## Functionality

- The feature works end-to-end.
- Buttons and actions are connected.
- No empty onPress handlers.
- Errors are handled.
- Loading states are handled.
- Empty states are handled.

## Code quality

- TypeScript passes.
- No unused imports.
- No obvious duplicated logic.
- Existing architecture is respected.
- No unnecessary dependency added.

## UX

- The screen is readable.
- The design matches Nice Price Bazar.
- The UI does not look generic or AI-generated.
- iOS safe areas work.
- Important actions are not hidden.

## Testing

- Main flow tested manually.
- Role behavior tested if relevant.
- API behavior tested if relevant.
- Mobile changes tested in Expo.
- iOS physical testing done for UI/navigation changes.

## Documentation

- Changed files summarized.
- Known limitations listed.
- TODOs are real and specific.
