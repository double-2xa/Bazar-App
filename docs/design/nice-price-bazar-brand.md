# Nice Price Bazar Brand Guide

## Brand source

The brand is based on the real shop sign:
- red signage
- yellow background
- local bazar feeling
- affordable products
- family/household/toys/general goods

## Brand keywords

- Affordable
- Friendly
- Practical
- Local
- Colorful
- Fast
- Useful
- Trustworthy

## App identity

The app should feel like a modern digital version of the physical shop.

It should not look like a generic marketplace template.

## Colors

Primary:
- Bazar Red: #C8102E
- Sign Yellow: #FFD21E

Secondary:
- Deep Red: #7A1020
- Warm Cream: #FFF8E7
- Charcoal: #1F1F1F
- Muted Brown: #6B4A2D

Functional:
- Success Green: #2E9D58
- Warning Orange: #F59E0B

## UI usage

- Use red for brand identity and primary actions.
- Use yellow for deals and highlights.
- Use cream for backgrounds.
- Use dark text for readability.
- Use glass only for navigation/action overlays.

## Do

- Use clean product cards.
- Use warm deal banners.
- Use subtle bazar personality.
- Use real copywriting.
- Use helpful empty states.
- Use location/delivery language.

## Do not

- Copy Amazon.
- Use too much red.
- Use too much yellow.
- Make everything glass.
- Use generic AI text.
- Add fake features.
